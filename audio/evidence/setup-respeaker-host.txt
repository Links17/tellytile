FoloTV reSpeaker runtime USB setup checks
The NVS failure and restart checks use stubs. The USB CLI also ran over a macOS virtual serial link.

Video PTS clock passed audio anchoring, burst handling, late/early frame bounds and a new session.
Native relay datagram validity and exact stereo PCM conversion passed.
Audio playout passed reorder, loss, late drop, idle recovery, cancel, tail drain, and session turnover.
USB setup passed split commands, invalid input, NVS round trip, atomic update failure and reboot order.
USB host tool passed framing, bounds, acknowledgement and single-write failure handling.
Virtual USB CLI passed: readiness handshake, Unicode SSID, custom port and save acknowledgement.

420106d0 T av_adpcm_decode
